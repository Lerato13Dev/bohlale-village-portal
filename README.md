🏠 Bohlale Village Residence Portal

A student-focused digital residence platform concept designed to make
residence communication, reporting and student participation easier.

🔗 Live Demo: [https://lerato13dev.github.io/bohlale-village-portal/]

💡 The Idea

The Bohlale Village Residence Portal started with a simple real-world
problem: important residence information and requests can become
scattered across WhatsApp, notices and word of mouth.

The idea was to bring useful residence services into one accessible
platform:

🛠️ Residence issue reporting

🚌 Bus schedules

👥 Current leadership and direct contacts

📢 Residence announcements

✍️ Student petitions

🤝 Subcommittees and emerging leaders

🎵 Bohlale Village social/TikTok access

This is a working front-end prototype demonstrating how the concept
could be implemented in a real residence environment.

🧠 My Role & Thought Process

I approached this as a real product problem, not simply a website
design.

I identified everyday residence challenges, mapped the features that
could be digitised, designed the user flows, prioritised mobile
usability, and considered practical areas such as student-number
privacy, direct WhatsApp/phone communication and future backend
integration.

I then used AI-assisted development to turn those requirements into an
interactive prototype, continuously reviewing, testing and refining the
result.

🤖 AI-Assisted Development

AI was used as a development assistant and technical collaborator,
rather than a replacement for my own thinking.

AI supported areas such as:

HTML, CSS and JavaScript development

Debugging and troubleshooting

UI/UX exploration

Responsive design

Data and interaction structures

Code improvement and iteration

I remained responsible for the original concept, problem
identification, requirements, feature decisions, user experience
direction, testing, iteration and final product vision.

This project reflects an AI-assisted engineering workflow where AI helps
accelerate implementation while the developer remains responsible for
the decisions and product being built.

🛠️ Built With

HTML5

CSS3

Vanilla JavaScript

LocalStorage for prototype persistence

GitHub Pages

The prototype is intentionally lightweight and can later be connected to
a real backend/database for authentication, reporting, notifications and
administration.

🚀 Why This Project?

This is not intended to replace Bohlale Village's existing systems
immediately.

It is a proof of concept that allows residence stakeholders to open
a live link and experience the idea without installing software.

The goal is to demonstrate:

What Bohlale Village could look like if everyday residence
communication and services were brought into one digital platform.
